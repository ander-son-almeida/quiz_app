# Ciência de Dados | Fundamentos Gerais | Estruturas de Dados e Algoritmos

Q9 [1] A busca binária numa lista ordenada de n elementos tem complexidade de tempo:
A) O(n)
B) O(n²)
C) O(1)
D) O(log n)
R: D
E: A cada passo, a busca descarta metade dos elementos restantes. Com 1.000.000 de itens, bastam cerca de 20 comparações (2²⁰ ≈ 1 milhão). Notação O ("big O") descreve como o custo cresce com n.

Q10 [2] Qual é a saída?
```python
pilha = []
pilha.append(1); pilha.append(2); pilha.append(3)
pilha.pop()
print(pilha.pop())
```
A) 1
B) 2
C) 3
D) [1, 2]
R: B
E: Pilha (stack) segue LIFO (Last In, First Out, o último a entrar é o primeiro a sair). O primeiro `pop` remove o 3; o segundo remove e devolve o 2.

Q11 [2] Qual é a saída?
```python
from collections import Counter
print(Counter("banana").most_common(1))
```
A) [('a', 3)]
B) [('b', 1)]
C) [('n', 2)]
D) {'a': 3}
R: A
E: `Counter` conta as ocorrências de cada elemento: a = 3, n = 2, b = 1. `most_common(1)` devolve uma lista com o par (elemento, contagem) mais frequente.

Q12 [2] Qual é a saída?
```python
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
print(fib(6))
```
A) 6
B) 5
C) 8
D) 13
R: C
E: A sequência de Fibonacci a partir de fib(0) é 0, 1, 1, 2, 3, 5, 8. fib(6) = 8. Essa versão recursiva tem custo exponencial; com memorização (cache) cai para O(n).

Q13 [3] O algoritmo de ordenação embutido no Python (`sorted`, `list.sort`) tem complexidade no pior caso e é estável. Estável significa que:
A) Nunca usa memória extra
B) Elementos com a mesma chave mantêm a ordem relativa original
C) Sempre roda em O(n)
D) Só ordena números
R: B
E: O Timsort tem custo O(n log n) no pior caso. Estabilidade permite ordenar em etapas: ordenar por nome e depois por nota mantém, entre notas iguais, a ordem alfabética.

Q14 [3] Qual é a saída?
```python
d = {"a": 1, "b": 2, "c": 1}
print({v: k for k, v in d.items()})
```
A) {1: 'a', 2: 'b'}
B) {1: ['a', 'c'], 2: ['b']}
C) Erro de chave duplicada
D) {1: 'c', 2: 'b'}
R: D
E: Ao inverter, a chave 1 aparece duas vezes; a última atribuição ('c') sobrescreve a primeira ('a'). Dicionários não aceitam chaves repetidas, mas não dão erro.

Q15 [3] Para descobrir se dois números de uma lista somam um valor alvo, a solução que percorre a lista uma única vez guardando os valores já vistos num set tem complexidade:
A) O(n²)
B) O(n log n)
C) O(n) em média
D) O(1)
R: C
E: Para cada x, testa-se se (alvo − x) já está no set, operação O(1) em média. A solução com dois laços aninhados testaria todos os pares, O(n²). É o problema clássico "Two Sum".

Q583 [3] (Adaptada — HackerRank 10 Days of Statistics) O número diário de chamados X segue Poisson com λ = 2. O custo diário é C = 100 + 10X². O custo esperado é:

Q704 [2] Um classificador tem VN = 90 e FP = 10. A especificidade é:
A) 0,90
B) 0,10
C) 0,11
D) 1,00
R: A
E: Especificidade = VN ÷ (VN + FP) = 90 ÷ 100 = 0,90. É a taxa de acerto entre os negativos reais; o complemento (0,10) é a taxa de falsos positivos.

Q705 [2] Os erros de previsão de um modelo de regressão foram 2, −2 e 4. O MAE é:
A) 1,33
B) 2,67
C) 2,83
D) 8,00
R: B
E: MAE (Mean Absolute Error, erro absoluto médio) = (2 + 2 + 4) ÷ 3 = 2,67. A média dos erros com sinal seria 1,33; o RMSE seria √(24 ÷ 3) ≈ 2,83.

Q720 [3] O coeficiente de correlação de Matthews (MCC) é recomendado para classes desbalanceadas porque:

Q753 [4] Qual é a saída de `np.argsort(np.array([30, 10, 20]))`?

Q754 [3] Qual é a solução de `np.linalg.solve([[2, 1], [1, -1]], [5, 1])`?
A) [1. 3.]
B) [3. 2.]
C) [2. 1.]
D) [5. 1.]
R: C
E: O sistema é 2x + y = 5 e x − y = 1. Somando: 3x = 6 → x = 2; logo y = 1. `solve` é mais estável e rápido que calcular a inversa.

Q755 [4] Um array NumPy com 10 milhões de números em float64 ocupa aproximadamente:
A) 10 MB
B) 40 MB
C) 800 MB
D) 80 MB
R: D
E: float64 usa 8 bytes por número: 10⁷ × 8 = 8 × 10⁷ bytes = 80 MB. Em float32 seriam 40 MB, com menos precisão.
