# Ciência de Dados | Fundamentos Gerais | Fundamentos Cloud
Q1 [1] Qual modelo de serviço em nuvem entrega máquinas virtuais, rede e armazenamento, deixando sistema operacional e aplicação sob responsabilidade do cliente?
A) SaaS
B) PaaS
C) IaaS
D) FaaS
R: C
E: IaaS (Infrastructure as a Service, infraestrutura como serviço): o provedor cuida de hardware, rede e virtualização; o cliente cuida do sistema operacional para cima. PaaS (Platform as a Service) entrega também o ambiente de execução; SaaS (Software as a Service) entrega o aplicativo pronto; FaaS (Function as a Service) executa funções sob demanda, como Azure Functions.
Q2 [1] O Azure Databricks é classificado mais adequadamente como:
A) Plataforma gerenciada de análise (PaaS)
B) IaaS puro
C) SaaS de CRM
D) Banco relacional OLTP
R: A
E: O provedor gerencia os clusters Spark, atualizações e escalonamento; o usuário escreve notebooks e jobs. CRM (Customer Relationship Management) é software de relacionamento com cliente; OLTP (Online Transaction Processing) é banco de dados transacional, como o que registra os pedidos de uma loja virtual.
Q3 [2] Na arquitetura medalhão (medallion) do Databricks, qual camada guarda dados limpos, tipados e deduplicados, ainda no nível de registro?
A) Bronze
B) Gold
C) Silver
D) Platinum
R: C
E: Bronze = dado bruto como chegou; Silver = dado limpo e conformado, linha a linha; Gold = dado agregado para consumo (tabelas de features, relatórios). Platinum não faz parte do padrão.
Q4 [2] Qual recurso do Delta Lake permite consultar uma tabela como ela estava numa versão anterior?
A) Z-Ordering
B) Auto Loader
C) Photon
D) Time travel
R: D
E: Time travel (viagem no tempo) lê o log de transações (_delta_log) com `VERSION AS OF 12` ou `TIMESTAMP AS OF '2026-10-01'`. Z-Ordering reorganiza arquivos para acelerar filtros; Auto Loader ingere arquivos novos de forma incremental; Photon é o motor vetorizado de execução.
Q5 [2] No Azure, o armazenamento de objetos com namespace hierárquico (pastas reais) usado como data lake é:
A) Azure Data Lake Storage Gen2
B) Azure SQL Database
C) Azure Cosmos DB
D) Azure Key Vault
R: A
E: ADLS Gen2 é o Blob Storage com namespace hierárquico e controle de acesso por ACL (Access Control List, lista de permissões por pasta/arquivo). Key Vault guarda segredos e chaves; Cosmos DB é banco NoSQL (não relacional).
Q6 [2] Um cluster Databricks com autoscaling de 2 a 8 workers e encerramento automático após 30 minutos ocioso busca principalmente:
A) Latência zero
B) Pagar só pela capacidade usada
C) Aumentar a precisão do modelo
D) Substituir o controle de versão
R: B
E: É elasticidade: o cluster cresce com a carga e desliga quando parado. O custo é cobrado em DBU (Databricks Unit, unidade de consumo por hora) mais o preço das VMs (máquinas virtuais). Exemplo: 8 workers ligados 24 h custam cerca de 4 vezes mais que 2 workers no mesmo período.
Q7 [3] Qual serviço do GCP (Google Cloud Platform) equivale ao armazenamento de objetos do Azure Blob/ADLS?
A) BigQuery
B) Pub/Sub
C) Cloud Storage
D) Cloud Run
R: C
E: Cloud Storage é o armazenamento de objetos do GCP, equivalente ao S3 da AWS. BigQuery é o data warehouse sem servidor; Pub/Sub é mensageria (publica e consome eventos); Cloud Run executa contêineres.
Q8 [3] No modelo de responsabilidade compartilhada da nuvem, quem responde por classificar os dados e gerenciar permissões de usuários num workspace?
A) O provedor de nuvem
B) A Databricks, exclusivamente

E: O provedor protege a infraestrutura física e o serviço; dados, identidades e acessos são sempre do cliente. No Databricks, o Unity Catalog é a ferramenta para isso.
# Ciência de Dados | Fundamentos Gerais | Qualidade de Dados
Q16 [1] A dimensão de qualidade que mede a proporção de campos obrigatórios preenchidos é:
A) Acurácia
B) Completude
C) Unicidade
D) Tempestividade
R: B
E: Completude = preenchidos ÷ esperados. Exemplo: 9.500 de 10.000 pedidos com CEP de entrega preenchido → completude de 95%. Acurácia = valor correto frente à realidade; unicidade = sem duplicatas; tempestividade (timeliness) = dado disponível a tempo.
Q17 [2] Numa tabela de pedidos, a data de entrega é anterior à data da compra. Qual dimensão de qualidade foi violada?
A) Completude
B) Unicidade
C) Disponibilidade
D) Consistência
R: D
E: Consistência verifica regras entre campos ou entre sistemas. Os dois campos estão preenchidos (completos), mas um contradiz o outro.
Q18 [2] Em PySpark, qual expressão conta duplicatas pela chave `id_pedido`?
A) `df.distinct().count()`
B) `df.groupBy().count()`
C) `df.count() - df.dropDuplicates(["id_pedido"]).count()`
D) `df.select("id_pedido").count()`
R: C
E: Total de linhas menos linhas únicas pela chave = linhas excedentes. Exemplo: 1.000 linhas e 990 pedidos distintos → 10 duplicatas. A opção A remove duplicatas de linha inteira, não pela chave.
Q19 [2] Uma regra "nota entre 0 e 10" numa base de avaliações de produtos é um teste de:
A) Unicidade
B) Tempestividade
C) Linhagem
D) Validade (domínio)
R: D
E: Validade verifica se o valor pertence ao domínio permitido (faixa, formato, lista). Exemplo: nota 15 é inválida mesmo estando preenchida.
Q20 [3] Em bibliotecas como Great Expectations ou nas expectations do Delta Live Tables, uma expectation é:
A) Uma previsão do modelo
B) Uma asserção declarativa sobre os dados, como "coluna não nula"
C) Um tipo de cluster
D) Uma métrica de negócio
R: B
E: Exemplo: `expect_column_values_to_not_be_null("renda")`. Cada execução registra quantas linhas passaram e, conforme a configuração, alerta, descarta ou interrompe o pipeline.
Q21 [3] O volume diário de uma tabela de eventos costuma ser 50.000 linhas e hoje chegou com 5.000. A técnica mais adequada para detectar isso automaticamente é:
A) Teste de unicidade
B) Monitoramento de volume com limites históricos (ex.: média ± 3 desvios)
C) Teste de formato de e-mail
D) Revisão manual mensal
R: B
E: É observabilidade de dados: compara volume, nulos e distribuições do dia com o histórico. Se a média é 50.000 e o desvio-padrão 2.000, o limite inferior é 44.000; 5.000 dispara alerta.
Q22 [4] Ao validar um modelo, você nota que 30% dos valores de renda são exatamente 1.000,00. A melhor interpretação inicial é:
A) A população é homogênea
B) Erro de arredondamento do Spark
C) Distribuição normal
D) Provável valor-padrão (default) inserido no sistema de origem; investigar e tratar como faltante disfarçado
R: D
E: Concentração anormal em um único valor redondo costuma indicar preenchimento automático. Tratar como renda real distorce o modelo; o correto é confirmar com o dono do dado e, se for o caso, recodificar como ausente.

# Ciência de Dados | Fundamentos Gerais | Modelagem de Processos BPMN
Q30 [1] BPMN significa:
A) Business Process Model and Notation
B) Basic Process Management Network
C) Business Planning and Monitoring Notation
D) Batch Processing Model Notation
R: A
E: É a notação-padrão (mantida pela OMG, Object Management Group) para desenhar processos de negócio. Bizagi, Draw.io e Visio são ferramentas que a implementam.
Q31 [1] No BPMN, uma tarefa (atividade) é representada por:
A) Círculo
B) Losango
C) Retângulo de cantos arredondados
D) Seta tracejada
R: C
E: Círculos são eventos (início, intermediário, fim); losangos são gateways (desvios); setas cheias são fluxo de sequência; setas tracejadas são fluxo de mensagem.
Q32 [2] Um gateway exclusivo (XOR) indica que:
A) Todos os caminhos seguem em paralelo
B) Exatamente um caminho é seguido, conforme uma condição
C) O processo termina
D) Uma mensagem é enviada
R: B
E: Exemplo: "Score ≥ 600?" → Sim: aprovar; Não: recusar. O gateway paralelo (AND, símbolo +) abre todos os caminhos; o inclusivo (OR, símbolo ○) abre um ou mais.
Q33 [2] Em BPMN, pools e lanes (piscinas e raias) servem para:
A) Indicar tempo
B) Representar dados
C) Separar participantes e responsabilidades
D) Marcar erros
R: C
E: Pool = participante (ex.: loja, cliente); lane = papel dentro dele (ex.: Vendas, Estoque, Expedição).
Q34 [2] Para comunicar dois pools diferentes (ex.: loja e transportadora), usa-se:
A) Fluxo de mensagem (seta tracejada)
B) Fluxo de sequência (seta cheia)
C) Associação pontilhada
D) Gateway paralelo
R: A
E: Fluxo de sequência só liga elementos dentro do mesmo pool; entre pools usa-se fluxo de mensagem.
Q35 [3] Um evento intermediário de temporizador (relógio) num fluxo de pós-venda modela:
A) Uma decisão
B) Uma tarefa manual
C) O fim do processo

R: D
E: O token (marcador de execução) fica parado até o tempo passar e então segue para a próxima tarefa, por exemplo "enviar pesquisa de satisfação".
Q36 [3] Ao mapear o ciclo de vida de um modelo (desenvolvimento → validação → aprovação), a ordem correta de um mapeamento AS-IS/TO-BE é:
A) Desenhar o TO-BE e implantar sem olhar o atual

Q39 [2] Qual é a saída?
```python
def f(a, lista=[]):
    lista.append(a)
    return lista
f(1)
print(f(2))
```

Q44 [3] Qual é a saída?
```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])
```
A) [0, 1, 2]
B) [2, 2, 2]
C) [0, 0, 0]
D) Erro
R: B
E: Late binding (ligação tardia): cada lambda busca `i` quando é chamada, e nesse momento `i` vale 2. Correção: `lambda i=i: i`.
Q45 [3] Um gerador (generator) como `(x**2 for x in range(10**9))` é preferível a uma lista porque:

Q47 [3] Qual é a saída de `sorted(["b10", "b2", "a1"], key=lambda s: (s[0], int(s[1:])))`?

Q48 [4] Qual é a complexidade de testar `x in conjunto` (set) e `x in lista` (list), em média?

Q51 [2] (Adaptada — padrão "Top Competitors", HackerRank) Tabelas `Submissoes(hacker_id, desafio_id, pontos)` e `Desafios(desafio_id, pontos_max)`. Qual consulta lista hackers com nota máxima em mais de um desafio?

Q56 [3] (Adaptada — padrão "15 Days of Learning SQL", HackerRank) Para escolher um único vencedor por dia, desempatando pelo menor `hacker_id`, a função de janela correta é:
A) `RANK() OVER (PARTITION BY dia ORDER BY qtd DESC)`
B) `ROW_NUMBER() OVER (PARTITION BY dia ORDER BY qtd DESC, hacker_id ASC)`
C) `DENSE_RANK() OVER (ORDER BY qtd)`
D) `COUNT(*) OVER ()`
R: B
E: Função de janela (window function) calcula sobre um grupo de linhas sem colapsá-las. `ROW_NUMBER` numera 1, 2, 3 sem empates; `RANK` daria dois "1" em caso de empate. A segunda chave de ordenação aplica a regra de desempate.
Q57 [3] Para valores 100, 100, 90, 80, quais são `RANK()` e `DENSE_RANK()` em ordem decrescente?
A) RANK 1,1,3,4 e DENSE_RANK 1,1,2,3
B) RANK 1,1,2,3 e DENSE_RANK 1,1,3,4
C) Ambos 1,2,3,4
D) RANK 1,2,2,3 e DENSE_RANK 1,2,3,4
R: A
E: `RANK` pula posições após empate (1, 1, 3); `DENSE_RANK` não pula (1, 1, 2).
Q58 [3] (Adaptada — padrão "Binary Tree Nodes", HackerRank) Tabela `BST(N, P)`, onde P é o pai. Para classificar cada nó como Root, Inner ou Leaf, a ordem correta do CASE é:
A) Leaf → Inner → Root
B) Root (P IS NULL) → Inner (existe filho) → Leaf (ELSE)
C) Inner → Root → Leaf
D) A ordem não importa
R: B
E: O CASE para no primeiro WHEN verdadeiro. A raiz é testada antes, porque ela também tem filhos e cairia em Inner. Exemplo: nó 2 sem pai → Root; nó 5 com filho 3 → Inner; nó 1 sem filhos → Leaf.
Q59 [3] (Adaptada — série "Weather Observation Station", HackerRank) P1 = (a, b) com a = MIN(LAT_N) e b = MIN(LONG_W); P2 = (c, d) com os máximos. Para mínimos (10, 20) e máximos (40, 60), a distância de Manhattan é:
A) 50
B) 70
C) 30
D) 40
R: B
E: Distância de Manhattan = |c − a| + |d − b| = |40 − 10| + |60 − 20| = 30 + 40 = 70. Em SQL: `ROUND(ABS(MAX(LAT_N)-MIN(LAT_N)) + ABS(MAX(LONG_W)-MIN(LONG_W)), 4)`. A euclidiana seria √(30² + 40²) = 50.
Q60 [4] Qual consulta calcula as vendas acumuladas de cada loja ao longo dos dias?
A) `SUM(valor) GROUP BY dia`
B) `SUM(valor) OVER (PARTITION BY loja ORDER BY dia ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)`
C) `SUM(valor) OVER ()`
D) `LAG(valor) OVER (ORDER BY loja)`
R: B
E: A janela vai do primeiro dia da loja até a linha atual. Exemplo: vendas 100, 50, 30 → acumulado 100, 150, 180. A opção C dá o total geral em todas as linhas; `LAG` traz o valor da linha anterior.
