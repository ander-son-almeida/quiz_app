# Ciência de Dados | Programação para Dados | Python e pandas
Q601 [1] Qual é a saída de `print(len("dados"))`?
A) 4
B) 6
C) Erro
D) 5
R: D
E: `len` conta os caracteres da string: d, a, d, o, s = 5.
Q602 [1] Em Python 3, qual é o tipo do resultado de `3 / 2`?
A) int
B) float
C) str
D) bool
R: B
E: `/` sempre devolve float (1.5). Para divisão inteira usa-se `//`, que dá 1.
Q603 [1] Qual é a saída de `print([10, 20, 30, 40, 50][1:4])`?
A) [10, 20, 30, 40]
B) [20, 30, 40, 50]
C) [20, 30, 40]
D) [10, 20, 30]
R: C
E: Fatiamento [início:fim] inclui o índice inicial e exclui o final. Índices 1, 2 e 3 → 20, 30, 40. Os índices começam em 0.
Q604 [2] Com `d = {"a": 1}`, qual é a saída de `print(d.get("x", 0))`?
A) None
B) Erro KeyError
C) "x"
D) 0
R: D
E: `get` devolve o valor padrão (segundo argumento) quando a chave não existe. `d["x"]` daria KeyError.
Q605 [2] Qual é a saída de `print(len("a,b,,c".split(",")))`?
A) 4
B) 3
C) 5
D) 2
R: A
E: O resultado é ['a', 'b', '', 'c']: a vírgula dupla gera uma string vazia entre elas. Quatro elementos.
Q606 [2] Qual é a saída de `print(f"{0.12345:.2%}")`?
A) 0.12%
B) 12.35%
C) 12.34%
D) 0.1235
R: B
E: O formato `.2%` multiplica por 100, arredonda com 2 casas e acrescenta %: 12,345 → 12.35%. (A representação binária de 0.12345 fica levemente acima, então arredonda para cima.)
Q607 [2] O que acontece ao executar `t = (1, 2, 3); t[0] = 9`?
A) t vira (9, 2, 3)
B) t vira [9, 2, 3]
C) Nada muda, sem erro
D) TypeError, porque tuplas são imutáveis
R: D
E: Tupla = sequência imutável. Para "alterar", cria-se outra: `t = (9,) + t[1:]`.
Q608 [2] Qual é a saída de `print(sum([i for i in range(5)]))`?
A) 15
B) 5
C) 10
D) 4
R: C
E: `range(5)` gera 0, 1, 2, 3, 4. Soma = 10. O 5 não entra.
Q609 [2] Qual é a saída de `print(dict(zip(["a", "b"], [1, 2])))`?

B) [('a', 1), ('b', 2)]
C) {'a': 'b', 1: 2}
D) Erro
R: A
E: `zip` emparelha os elementos das duas listas; `dict` transforma os pares em chave: valor.
Q610 [2] Qual é a saída de `print(list(enumerate(["x", "y"], start=1)))`?
A) [(0, 'x'), (1, 'y')]
B) [('x', 1), ('y', 2)]

Q611 [3] Qual é a saída?
```python
import copy
a = [[1, 2], [3]]
b = copy.copy(a)
b[0].append(9)
print(a)
```
A) [[1, 2], [3]]
B) [[1, 2, 9], [3]]
C) [[9], [3]]
D) Erro
R: B
E: Cópia rasa (shallow copy) cria uma lista nova, mas as listas internas são as mesmas. Alterar `b[0]` altera `a[0]`. `copy.deepcopy` copiaria também os níveis internos.
Q612 [3] Numa função `def f(*args, **kwargs)`, a chamada `f(1, 2, x=3)` produz:

C) args = (1, 2, 3) e kwargs = {}
D) Erro
R: A
E: `*args` recolhe os argumentos posicionais numa tupla; `**kwargs` recolhe os nomeados num dicionário.
Q613 [3] Qual é a saída?
```python
try:
    print("A")
    1 / 0
except ZeroDivisionError:
    print("B")
finally:
    print("C")
```
A) A
B) A C
C) A B C
D) B C
R: C
E: Imprime A, a divisão por zero dispara a exceção, o bloco except imprime B e o finally sempre executa, imprimindo C.

Q617 [2] A tabela `clientes` tem 100 linhas com `id` único. A tabela `pedidos` tem 150 linhas e todo `id_cliente` existe em `clientes`. Quantas linhas tem `clientes.merge(pedidos, left_on="id", right_on="id_cliente", how="left")`?

Q618 [3] Para preencher valores ausentes da coluna renda pela mediana, o código correto é:

E: `fillna` devolve uma nova Series; atribui-se com `df["renda"] = ...`. `isna().sum()` conta quantos faltam. Em modelos, calcule a mediana só no treino para não vazar informação do teste.
Q619 [3] A diferença entre `pd.cut` e `pd.qcut` é:

Q620 [3] Qual é o resultado de `df.groupby("loja").agg({"valor": "sum", "devolvido": "mean"})`?

Q621 [3] Para calcular `df["preco_unitario"] = df["valor_total"] / df["quantidade"]` em 10 milhões de linhas, a forma mais rápida é:

Q624 [4] Qual é a saída de `print(0.1 + 0.2 == 0.3)` e qual a forma correta de comparar?

Q625 [4] Para criar uma coluna com a nota média da turma de cada aluno, mantendo o número de linhas do DataFrame, usa-se:

Q637 [3] A subconsulta `SELECT id FROM bloqueados` contém um valor NULL. O que retorna `SELECT * FROM clientes WHERE id NOT IN (SELECT id FROM bloqueados)`?

Q648 [2] Qual expressão PySpark cria uma coluna que vale 1 quando a temperatura passa de 30 graus e 0 caso contrário?
A) `F.when(F.col("temp") > 30, 1).otherwise(0)`
B) `if temp > 30: 1`
C) `F.case(temp > 30)`
D) `df.temp > 30 ? 1 : 0`
R: A
E: `F.when(condição, valor).otherwise(valor)` é o equivalente ao `CASE WHEN` em PySpark (`F` = `pyspark.sql.functions`). `if` do Python não opera sobre colunas distribuídas.
Q649 [2] Chamar `df.cache()` é útil quando:

R: C
E: Sem cache, cada ação reexecuta todo o plano desde a leitura. O cache ocupa memória do cluster; libere com `unpersist()`.
